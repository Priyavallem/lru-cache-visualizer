# LRU Cache Visualizer

An interactive web application that demonstrates the working of an **LRU (Least Recently Used) Cache** using real-time visualization and animations.

##  What is LRU Cache?
LRU Cache is a caching strategy where the **least recently used item is evicted first** when the cache reaches its capacity.  
It is widely used in **operating systems, databases, and web browsers**.


##  Features
- Set cache capacity dynamically
- Perform **GET** and **PUT** operations
- Automatic eviction of least recently used item
- Real-time visualization of cache state (MRU → LRU)
- Smooth UI animations
- Reset cache functionality


##  Tech Stack
- HTML5
- CSS3
- JavaScript 


##  Core Concepts Used
- LRU Cache algorithm
- HashMap (JavaScript Map)
- Doubly Linked List
- DOM manipulation
- Event handling


##  How to Run
1. Clone the repository
2. Open `index.html` in any modern browser
3. Enter cache capacity and start using GET / PUT operations


##  Use Case
This project helps in understanding how caching mechanisms work internally and is useful for learning **DSA concepts with visualization**.
